# HNK-008 / HNK-018 / HNK-019 — Commit только из index

Staging проверен 7b14810. Цель: сообщение пользователя и настоящий commit A+B, при этом C остаётся worktree. Никаких Conventional Commit требований к пользовательскому сообщению и никаких stage-all.

1. Core CommitSnapshot привязывает запрос к exact index checksum, HEAD oid/symbolic identity/root/operation. Index lock после hook phase, fresh read и guard checks. Смена ветки на другую с тем же oid тоже stale. Unresolved stages/empty index-tree/active operation — structured refusal; operation completion — HNK-009.
2. gix edit_tree(empty) + index stage-zero entries + write; new_commit/signing options/CommitRef signing + object write; native ref transaction/expected old value + HEAD identity protection and reflog. Attributes already applied during staging; commit никогда не читает рабочие файлы для дерева.
3. Обычные pre-commit/prepare-commit-msg/commit-msg/post-commit через configured hooksPath, gix command primitives/context; message UTF-8 bound, Git-style cleanup. Failure до ref update оставляет HEAD/index целыми, user message в UI. Hook-собственные изменения не откатываются; index change после hook требует refresh/review. Подпись через официальные gix APIs, ошибка signing — ошибка, без unsigned retry. Более сложные hook/ref formats аудировать до записи, отдельный явный отказ если семантика ещё не доказана.
4. Isolated tests с independent Git oracle: A staged+B partial → commit A+B/C worktree, parents/tree/reflog/identity/message, unborn/detached/linked/SHA-256, empty/missing identity/conflicts/locks/stale, successful and failed hooks, actual SSH signing and signing-program failure. Owner config не меняется.
5. UI отдельный owned GPUI input на EntityInputHandler (official Apache-2 GPUI example/API; Zed editor не копировать). Unicode cursor/selection, clipboard, multiline message/undo/redo. Bounded writer общий с staging, busy/read generations/close guard, locale changes retain message/selection. Commit success clearing message only after confirmed result, failed message retained.
6. scripts/dev check/check-ui/build-ui/smoke с native commit scenario and Git oracle; точный tested commit дописать после checkpoint. HNK-018 core и HNK-019 UI отдельно проверяемые части; parent HNK-008 done только после обеих.

Primary sources checked 2026-10-05: https://docs.rs/gix/0.88.0/gix/struct.Repository.html ; https://git-scm.com/docs/git-commit ; https://git-scm.com/docs/githooks ; exact local gix/GPUI registry sources.
