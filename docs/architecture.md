# Границы реализации

UI/UX по прямому запросу владельца следует Zed: компактные панели и вкладки, тёмная палитра, спокойные разделители, нижняя строка состояния и клавиатурные действия. Это собственная GPUI-композиция; GPL editor/workspace Zed не копируется. Read-only One Dark theme изучена как визуальный ориентир; её MIT license проверена, тема целиком не переносится. Настройки и checkout Zed не изменяются.

Два crate: hunkra-core (обычные модели Git/status/document/diff, gix adapter), hunkra (GPUI standalone + Fluent + app-local settings). UI получает snapshots и структурированные ошибки. Переводы на границе UI. Блокирующие операции в ограниченном worker; snapshot list и выбранный diff имеют независимые поколения.

В будущей Zed интеграции standalone host заменяется адаптером Panel/Item, GitStore, host buffers/unsaved content и remote projects. Shared view не открывает окна и не читает standalone settings. Второй GitStore не создаётся.

Изучен read-only Zed @ 0c70487f830b10abde93ef75a0772a4552744f15: crates/project/src/git_store.rs (GitStore), crates/workspace/src/dock.rs (Panel), crates/workspace/src/item.rs (Item), crates/git_ui/src/{git_panel,staged_diff,unstaged_diff,text_diff_view}.rs, crates/buffer_diff/src/buffer_diff.rs (BufferDiff/DiffOperations), crates/editor/Cargo.toml. Editor связан с language/text/multi_buffer/project/workspace и не самостоятельный пакет. Код не копировался; GPUI Apache-2.0 — самостоятельная библиотека. API extension panels не считается подтверждённым.

Upstream main checked through official GitHub API on 2026-10-05: 8fda6e46539bdf056e3e326cfcab7deea831ff40. It differs from local 0c70487f; Hunkra does not assume the local clone equals latest. Both expose split GPUI/platform crates on main, whereas the selected official registry 0.2.2 uses Application directly and includes native backends. Source paths and their licenses were read in the local snapshot; no claim that Zed extension APIs provide arbitrary panels. GPL editor/text/workspace have not been copied.

Host has independent bounded status, selected diff, history and remote readers, a settings writer and one serialized index/commit/branch/operation/Result/network writer. Each has at most one active/one replaceable pending/one reply. ViewState rejects older diff generations. History constructs its thread-confined gix service inside the worker, walks one pinned tip incrementally and retains eight 100-row pages; a dropped page reply is retried idempotently. Commit/file/explicit-parent raw blob reads share its generation gate. HistoryView opens no windows and reads no standalone settings. Lazy uniform lists render visible files/paired rows. Currently a 2-second reconciliation timer refreshes status and selected diff; this is functional but watcher/native-load metrics remain HNK-006/013. Refresh with unchanged bytes retains the prior diff identity and selected rows. If actual bytes change, row selection is invalidated.

Index writes accept an immutable DiffSnapshot plus independent removed/added line sets. The opaque guard contains root, exact index digest, HEAD, raw worktree bytes and mode. supported() checks actual variants before any mutation; split LINK detection uses State::from_bytes, because File::at already dissolves it. Under gix-lock, the writer reopens the repository, rereads versions, builds an index document, writes a blob and replaces only the selected entry. TREE cache is invalidated; lock is synced and guards checked again before atomic commit. Rendered line/action callbacks are bound to their immutable diff identity; a replaced frame cannot use old coordinates on a newer document. UI invalidates old reader generations while writing, refreshes afterward and preserves write errors across polling. Ordinary window closure waits for the accepted writer; forced process termination has standard Git-lock limitations.

Owned text.rs provides scalar-safe UTF-16/native IME mapping, grapheme navigation, exact UTF-8/newline bytes and bounded minimal-edit undo/redo. editor.rs uses GPUI EntityInputHandler, shapes visible rows and derives caret/selection/hit-testing from that exact painted revision. Commit and independent conflict Result have native multiline inputs; placeholder changes retain text/selection/undo. A refused oversized/NUL insertion emits a localized UI error without altering text. The shared writer freezes input and snapshots the last rendered CommitSnapshot; failures retain user text, confirmed success clears it. Pending ordinary close is canceled on write failure so the user can inspect and retry. Result Save changes only worktree; Mark resolved writes stage zero/REUC separately; Continue requires a current resolved index. Dirty navigation and destructive operation actions have explicit confirmations. Clipboard/dispatch have an isolated GPUI platform test; native Wayland smoke exercises composition callbacks and shaped coordinates without modifying owner clipboard. No GPL Zed code was copied, and product licensing remains the owner's choice.

Status reader now returns a shared-HEAD/index/state bundle containing RepositorySnapshot, gix BranchSnapshot and exact OperationSnapshot. Operation metadata is an immutable Arc in the UI and accepted write requests, so rendering does not copy up to 4MiB each frame. Last-rendered snapshots bind branch/operation actions; one writer freezes both inputs and invalidates pending reads. Branch selection does not imply checkout; switch/merge/rebase buttons capture immutable targets separately. Source guards reject changed index/HEAD/raw sequencer metadata and target refs before CLI launch. Git owns its usual locks; the app does not hold index.lock while starting Git. Own single-line NativeEditor emits Enter and refuses newline paste/composition without rewriting user bytes.

NetworkView owns bounded single-line inputs and last-rendered immutable NetworkSnapshot; no render/locale network calls. It emits owned NetworkCommand to the standalone host, which serializes core init/clone/fetch/upstream/push/pull on the existing writer. Creation and ff-only integration use the Result/navigation guard; cancel retains fields/draft, save-before-creation saves filesystem Result first. Ref/config-only successful outcomes retain selected diff coordinates until actual refreshed versions differ. Accepted writer and concrete product prompts freeze network inputs; accepted close waits, failure cancels it. Remotes/creation view opens no window, reads no standalone settings and persists no credential-capable URL inputs. Backend audit/fallback decisions remain in core NetworkCapability, not UI heuristics.

Selected diff worker now owns DiffReader with four-entry/24MiB retained buffer capacity limits. Each read reopens current Git/config/attrs/filter state, reads exact bounded sources and compares index/HEAD/raw worktree/mode before sharing a cached immutable alignment. Same timestamps do not justify reuse. Read/convert failure cannot return cached success. Changed sources replace the old path/comparison version; LRU evicts other selections. UI receives Arc rows without deep cloning and rejects older generations. Cache budget excludes allocator overhead and external/active shared snapshots; local RSS is measured separately. No persisted stat/index changes are introduced by reading.
